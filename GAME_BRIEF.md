# TWIF GAME BRIEF

## Working Title
TWIF: Subnet One

## Core Premise
A third-person neo-samurai action-comedy set inside Bittensor.

TWIF is a hooded samurai / ninja-style Shiba who enters the Bittensor network and progresses through subnet worlds. There are 128 total nodes/subnets in the wider concept, but this game jam build only contains:
- the hub
- one playable subnet / one complete 10–15 minute level

At the start, 127 nodes are inactive.
Completing the demo level lights up 1 of 128.

## Tone
Dead-serious samurai hero inside a ridiculous crypto-native world.

The game should feel like:
- compact GTA / LEGO-style action-adventure
- simple and immediately fun
- funny through contrast
- packed with lore, posters, references and easter eggs

## Core Gameplay
- third-person exploration
- simple sword combat
- short driving sequence
- short chase / action set piece
- compact mission structure
- 10–15 minute playable story
- free roam after completion if time allows

## World
A neo-samurai Bittensor world:
- Japanese-inspired shrines, dojo, lanterns, streets
- mixed with convenience stores, billboards, trading screens, network gates, modern city props
- not educational or overly explanatory
- Bittensor references should reward insiders without confusing outsiders

## Main Characters
- **TWIF** — playable hero, hooded Shiba ronin, sword, glowing eyes
- **Max Sensei** — dojo master / trainer / mentor
- **Const** — revered / godlike figure, shrine / idol / founder-energy presence
- **Mog Motivational** — motivational meme presence in posters, ads, ambient references
- **Sam Dare** — legacy / cautionary old lore, abandoned relics and environmental references only

## Story Spine
TWIF enters Bittensor and completes the first subnet/world.
The level should end with TWIF earning an artefact / reward from that subnet and returning to the hub.
The hub updates from 0/128 to 1/128 complete.

## Important Constraints
- This is NOT 128 levels.
- This is one polished vertical slice.
- Prioritize movement, combat, driving, readability and fun.
- Every final 3D object must be generated as code using the 404 recipe.
- Reuse assets where possible.
- Mobile + laptop should both work.
